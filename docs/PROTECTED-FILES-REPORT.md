## How the new behaviour reaches the protected code without editing it

* `autopatch/api/patches.py` already asks `ext.get("llm") or GeminiClient(cfg)` for its client. Backend V2 registers a `GuardedLLM` under `ext["llm"]` (a wrapper around the SDK or HTTPS client), so the key check and secret scan run before every request.
* `gemini_client.py` is imported and reused (`AIError`, `classify`, `redact`), never edited. The new error kind `secrets_detected` is a subclass of `AIError` defined in `guarded_llm.py`.
* `patch_diff.py`, `patch_prompt.py`, `patches.py` and `static/js/patches.js` are untouched, so diff validation, approval, verification and rollback behave exactly as before.
