Features

Everything you need to go from bug to verified fix.

Each feature below is part of this application and connected to real scan and repair data.

⬆

Repository upload

Hardened ZIP handling rejects path traversal, symlinks and oversized archives. Your original upload is never modified.

◎

Scan Center

Runs your tests, Ruff, Bandit and entry points in a temporary copy with time limits, and shows each stage live.

⚠

Bug Intelligence

Severity, confidence and evidence kept separate. Every bug has its file and line, traceback, root cause and a clear label: runtime-confirmed or static.

✎

AI Repair Studio

Gemini drafts a minimal fix with an explanation. You compare original and proposed code side by side, then approve or reject.

✓

Verification Center

Accepted patches are applied to a copy and your tests run before and after. Regressions are reverted automatically.

☰

Reports

A health summary, detection and repair statistics, and a Markdown export you can attach to a pull request.

The AutoPatch path

From a pile of code to a verified fix.

Scroll through the four steps.

1

Upload your repository

Drop in a ZIP. It is checked, indexed and stored untouched. Nothing runs at upload time.

2

Detect software bugs

AutoPatch runs your tests, Ruff, Bandit and entry points in a temporary copy, with time limits.

3

Repair with AI

Pick a bug and ask for a fix. You see an explanation and the exact change, and nothing is applied until you approve.

4

Verify, then decide

Your tests run before and after the patch. You see real counts, and you can roll back at any time.
